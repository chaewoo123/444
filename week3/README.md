## 재현 방법 (Windows PowerShell 5.1)
1. `oc.txt`에 국가법령정보 OPEN API OC 값을 넣는다 (저장소에는 없음 — `.gitignore`)
2. `law_api.ps1` — 법령·조례 조회, 응답 원본을 `raw/`에 저장 (OC는 `***`로 가림)
3. `extract_articles.ps1` — `raw/` → `원문_조문모음.txt`
4. `analysis_400m.ps1 -Scope 원정의|경계내` — OSM 데이터로 K1~K4 계수
5. `make_map.ps1` → `map.svg`, `build_report.ps1 -Team LUOGO` → `제출본.html` → 브라우저 인쇄(A4 세로)로 PDF
